# Workflow: Analyze Writing Voice

**Owner:** folio
**Objective:** Learn the user's personal writing style from their own samples and synthesize it into reusable, per-register style profiles that the `write-like-me` skill uses to draft in their voice.

This is folio's first-use onboarding for voice. Run it the first time the user wants writing in their own voice and no profile exists yet, or any time they want to resync after adding samples. It mirrors a deep human-analysis: parallel agents each study one slice of the writing, then their findings are synthesized into a usable guide.

---

## When to run

- The first voice-drafting request, when `references/writing-voice/profile-professional.md` / `profile-creative.md` are still placeholders.
- `/analyze-writing-voice`, "learn my writing style", "study how I write".
- Resync, after the user adds or changes samples.

---

## Registers and dimensions

- **Registers** (run a register only if it has samples):
  - `professional` — formal, academic, or work writing.
  - `creative` — casual, personal, or narrative writing.
- **Dimensions** per register (4): `voice`, `vocabulary`, `sentences`, `organization`.

A register with samples produces four analysis docs; both registers produce eight.

---

## Step 1 — Collect samples

Ask the user to add their own writing to `references/writing-voice/samples/`:

- `samples/professional/` — formal, academic, or work pieces.
- `samples/creative/` — casual, personal, or narrative pieces.

Guidance to give them: 2 to 5+ pieces per register; more and more varied samples produce a sharper profile. Whole pieces beat snippets. The two registers are independent — doing only one is fine. Accept `.md` or `.txt`. Name samples `NN-short-slug.md` (e.g. `01-client-proposal.md`) so resyncs stay ordered and new files are obvious. Wait until the samples are in place before continuing. Hard minimum: do not proceed to Step 2 for a register with fewer than 2 sample files; if a register has only one short sample, tell the user it will produce a thin, unreliable profile and ask for more first.

---

## Step 2 — Parallel deep analysis

For each register that has samples, spawn the four `writing-style-analyzer` sub-agents IN PARALLEL — one per dimension. (One register = 4 agents; both = 8.) Pass each agent its `register`, `dimension`, `samples_dir` (`references/writing-voice/samples/{register}/`), and `out_path` (`references/writing-voice/analysis/{register}-{dimension}.md`). Each agent reads all samples in its register, analyzes its one dimension, and writes its findings in the analyzer's required format. Wait for all of them to finish.

---

## Step 3 — Synthesize per-register profiles

For each register, read its four analysis docs and write `references/writing-voice/profile-{register}.md` — a tight, directly-applicable style guide. Open it with a provenance blockquote, then the sections below:

- **Provenance** — the first line is `> Generated by workflows/folio/analyze_writing_voice.md from references/writing-voice/samples/{register}/. Loaded by the write-like-me skill on every {register}-register draft.`
- **Voiceprint** — a 2 to 3 sentence summary of how this person writes in this register.
- **Do this** — the load-bearing positive patterns from all four dimensions, written as direct instructions.
- **Never do this** — the conspicuously-absent habits, written as hard rules.
- **Cadence samples** — a handful of representative (anonymized) lines that show the rhythm.
- **AI tells to watch** — a pointer to `references/signs-of-ai-writing.md`, naming the specific tells this user's natural style already avoids so the `write-like-me` skill keeps avoiding them.

Keep each profile under ~120 lines — it loads on every voice-draft.

---

## Step 4 — Confirm and test

Show the user a short recap of each profile, then write one short paragraph in their voice on a neutral topic as a live test. Let them react. Refine the profile from their feedback before calling it done — a profile the user has to keep correcting is not finished.

---

## Step 5 — Finalize

The profiles are now live. Tell the user that folio will draft in their voice through the `write-like-me` skill from here on, and that they can resync any time by adding samples and re-running this workflow. The `analysis/` docs are intermediate — they can stay for reference or be cleared.

---

## Self-Improvement

If the test paragraph in Step 4 missed badly, the cause is usually too few samples or a dimension the analyzer under-weighted. Note the gap and refine this workflow or the `writing-style-analyzer` sub-agent so the next run is sharper.
